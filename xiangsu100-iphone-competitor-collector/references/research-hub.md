# 统一研究总览交付

多份 HTML 报告、图库和过程记录需要合并交付时，生成一个可直接打开的总览 HTML。总览应内嵌每份来源正文，提供分组导航、全文搜索、内部链接跳转、锚点、图片放大、原文件入口及历史记录标识；不能只列链接。当前分析和历史阶段记录明确区分。完整去重图库仍按原约定保留，不因总览缩减。

使用 `scripts/build_research_hub.py --config hub-config.json`。配置中显式列出每份来源 HTML 的 `path`、`group`、`title`、`kind`、`archive`、`rank`，并给出 `output`；路径相对于配置文件。显式列表避免重复构建时把总览本身再次收录。生成器把本地 JS/CSS 内联到来源正文，并保存原文件的 `base` 地址，使原图仍从原目录读取；迁移时必须保留图片来源目录。缺少资源时生成失败并列出缺口，不伪称独立离线包。

```json
{
  "title": "研究总览",
  "output": "研究总览.html",
  "documents": [
    {"path": "报告/竞品A.html", "group": "竞品A", "title": "任务分析", "kind": "分析", "rank": 0, "archive": false},
    {"path": "记录/竞品A.html", "group": "竞品A", "title": "采集记录", "kind": "历史记录", "rank": 2, "archive": true}
  ]
}
```

验收：检查来源数量与 hash、中文/空格路径、资源存在性、零结果搜索、内部文档与锚点导航、原图和放大行为。静态检查和模拟 DOM 只说明逻辑与路径可解析；只有在真实浏览器打开并逐项试用后才标记浏览器视觉验收通过。
