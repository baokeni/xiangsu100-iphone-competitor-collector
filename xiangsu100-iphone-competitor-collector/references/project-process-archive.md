# 项目过程与AI协作

接续研究、形成重要判断或修订、暂停及交接时读取。AI从实际对话、材料与产物中持续整理少量关键记录，用户核对真实取舍和贡献；无需每阶段询问是否记录，不复制全部聊天，也不要求学生填写大表或JSON。

## 复用已有记录和结论入口

- 优先使用项目已有任务笔记或过程档案，后续更新同一文件。无既有位置时，在研究项目保存`项目过程与交接.md`；可参考[可选模板](../assets/project-process-template.md)，不把学生档案写入Skill安装目录。
- 研究任务卡、当前分析/报告及适用的`cross-analysis.json`保持各自原用途的有效结论入口。档案记录当时的判断、变更、来源和版本，链接当前入口，不另抄一份“当前结论”使其漂移。已有任务笔记同时承载任务卡时，保持其既有角色，在过程条目中链接受影响内容及历史版本。
- 完整研究澄清问答继续按[澄清留档](research-clarification.md)保存在原位置；过程档案只链接该记录和采用决定。常规进度沿用[教学节奏](teaching-rhythm.md)规定的已有笔记，不再新增竞争性的状态文件。
- 先继承本次研究问题、用途、范围、已确认条件、材料和待决项。区分用户原话、AI建议、研究假设与真实决定；已有确认不重问，源码/截图现象或历史说明不自动升级为用户认可。

## 在真实研究中留下关键记录

按实际发生的研究过程记录，不强制固定阶段或凑条目。纯机制探索也适用，不因此添加目标产品、改版方案、手机操作、周期跟踪或新run目录；这些仍按原任务与授权决定。

| 记录角度 | 留下的内容与来源 |
| --- | --- |
| 研究判断 | 研究问题为何如此界定，为什么选择或排除某竞品、比较条件与迁移限制；考虑了什么、采用/放弃什么、原因及决定者。推荐、计划、实际观察与采用分别写明。 |
| 证据和结论 | 材料/截图/事件及来源日期、任务分支计划与实际覆盖、证据筛选依据；观察、推断、未知原因与待验证主张分开。结论被质疑或修订时保留原判断、反例/新依据、当前产物入口。 |
| 项目适配 | 本项目为何调整输入、提示、分析方法、顺序、采集/检查方式或人工处理，改前改后和观察证据是什么。普通分析修订不叫Skill升级；通用指令改变另记来源与版本/文件身份。 |
| 协作贡献 | 用户/学生、AI、教师各自实际提出、选择、检查或修改了什么。引用原话或明确标为转述；没有表达的个人动机保持未知，不把AI整理写成学生独立完成。 |
| 结果和反思 | 采用的输入/输出版本、首轮/失败/修订、检查及未测边界、认可范围。基于真实观察提出具体协作改进；没有依据不补造效率、能力或业务收益。 |

旧项目补记标为“事后回顾”并附来源。未发生的部分标未开始/跳过及原因，不把其他项目的材料拼成个人全流程。静态材料、工具实际操作、语义审阅、用户认可与真实效果分别记录；模拟画像/AI走查不能写成真实用户研究。现有[分析质量评审](case-quality-review.md)继续用于方法质量检查，不代替个人过程档案。

## 交接时更新同一档案

给出当前任务/报告入口、版本和材料路径，已定/未定事项、观察与判断的依据、当前修订和理由、实际贡献、已查/未查及下一任务范围。需要设计决策时链接原决定与验证任务；探索任务没有设计落地就如实保留，不为了交接补造方案或效果。对方应能从这些入口接续，缺材料说明影响，不让记录整理阻塞已获授权的独立工作，也不因整理档案自动授权新采集或发布。

## 按需整理后续材料

用户需要时，从已有研究档案和实际材料派生；研究尚未全部完成也可整理已知内容与缺口。不默认每阶段同时输出三份长报告，不把它们变为原研究的额外必选延伸。

- **作品集框架与排版交接**：提炼研究问题、选样理由、关键证据、比较发现/适用条件、判断与取舍、个人贡献，以及对后续设计的实际影响（若有）；给建议页序、每页结论、素材/证据映射和缺口。内容框架不等于排版完成，不补造淘汰方案、团队合作、用户反馈、上线或指标。
- **面试准备与模拟问答**：用户提供的原题优先，AI改写与新增题目分别注明。按研究问题/选样与可比性、证据可信度和覆盖、观察与推断、方法取舍、结论修订、设计迁移、协作分工、失败与AI纠错、情景变化等角度选题，不固定题量。学生先回答，再结合实际回答与材料追问；区分真实经历、方法解释和假设迁移，不预编虚假的第一人称经历。可保留“具体问题｜学生回答及证据｜待确认原因｜下一步练习”；档案可支持的答案要点与需本人确认的思考分开。
- **个人AI工作流与协作反思**：串起本项目实际采用、跳过或替换的步骤，注明输入、方法/Skill、AI辅助、人工判断、检查和交接。按“观察与证据→可能原因（待核实）→具体练习→检查信号”提出建议；没有对照或长期证据，不宣称效率、研究效果或个人能力已提升。

这些材料来自同一份过程索引与现有结论来源，不新建一份互相竞争的研究事实库。文档产出、结构检查、真实研究运行、学生独立使用和作品集/面试效果分别说明。
