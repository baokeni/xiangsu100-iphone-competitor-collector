# 筛选商品：材料说明模板

这是教学示范，尚未附真实截图或录屏。请用自己的产品名称、操作过程与原件填写；不要把示范任务当成已经观察到的产品事实。

## 任务说明

- 我想研究：用户怎样筛选出预算范围内的商品，并确认条件已经生效。
- 本轮用途：了解竞品机制 / 为目标产品改版提供依据（选择一项）。
- 目标产品与改版目标：仅需要改版时填写；纯探索可写不涉及。
- 示例任务：在运动鞋列表里寻找展示价格不高于 300 元的候选商品。
- 本轮范围：列表、筛选、应用、修改/取消；不进入下单或付款。

## 这个任务可以怎样留材料

以下是参考状态，不是固定张数。实际没有的页面或操作注明情况，不补造。

| 状态 | 需要看到什么 | 对应原文件或录屏位置（可由 AI 整理） |
|---|---|---|
| 筛选前 | 列表、入口、搜索词或已有条件 | |
| 打开筛选 | 实际出现的选项和操作 | |
| 选择条件 | 选中状态、确认/应用方式 | |
| 应用后 | 列表、条件提示与结果反馈 | |
| 修改或取消 | 重新打开后的状态及调整方式 | |
| 清除后 | 当前条件与列表状态 | |

若只有连续录屏，可直接提供原件，不必先手动截六张图。若只有截图，可以保持原文件名并说明先后；无法确认操作过程的部分仍记未知。没有精确的预算选项时，记录实际替代路径，不假设每个产品都支持相同筛选。
